# SOC Analyst L1 – Case Studies

This section contains practical cybersecurity case studies based on
security alerts investigated in the TryHackMe SOC L1 Alert Triage lab.

Each case study focuses on understanding the security event, analyzing
available evidence, identifying potential threats, and documenting
the investigation outcome.

## Case Studies

| No. | Case Study | Verdict | Severity |
|---|---|---|---|
| 01 | Double-Extension Malware Download | True Positive | High |
| 02 | Potential Data Exfiltration | False Positive | Critical |
| 03 | GitHub Repository Download | False Positive | Low |

## Objectives

- Understand different types of security alerts.
- Identify suspicious files, URLs, and network activity.
- Analyze security indicators and available evidence.
- Differentiate between True Positives and False Positives.
- Understand the responsibilities of a SOC Analyst L1.
- Improve incident documentation and investigation skills.

## Learning Approach

These case studies are based on simulated SOC investigation
scenarios and are intended for educational and portfolio purposes.
